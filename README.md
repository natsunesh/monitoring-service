# monitoring-service
Сервис мониторинга закупок и уведомления


Приложение состоит из двух частей:
- `GUI\GUI_zakupki.exe` — интерфейс пользователя.
- `Service\Monitor_zakupki.exe` — фоновая служба.

## Требования
- Windows 10/11.
- Права администратора для установки службы.

## Установка

1. Распакуйте архив в удобную папку.
2. Запустите `install-service.bat` от имени администратора.
3. Дождитесь сообщения об успешной установке службы.
4. Запустите `GUI\GUI_zakupki.exe`.

## Удаление

1. Запустите `uninstall-service.bat` от имени администратора.
2. Дождитесь удаления службы.

## Структура папок(в релизе)

- `GUI\` — интерфейс.
- `Service\` — служба.
- `install-service.bat` — установка и запуск службы.
- `uninstall-service.bat` — удаление службы.
